# `Spec` — Across a cycle boundary

Read this file when a task has not reached completion this cycle, or a new goal continues the theme of a closed one. Shared rules — `.claude/agents/spec.md`.

## Across a cycle boundary

| Case | What happens |
|---|---|
| A task didn't reach completion this cycle — budget exhausted, or the kit has nothing left to fix | **the same card continues** in the next cycle of the same goal, under the same number. The new cycle slices only the **remainder**; what's done isn't written out twice |
| A new **goal** continuing the same theme — a second version, a rework after feedback once the old one closed | **a fresh card**, with a field "previous version: path to the earlier card". Different arrival criterion, different `GOAL.md`: the thing's history is traced through a chain of links, not by merging files with different readiness criteria |
