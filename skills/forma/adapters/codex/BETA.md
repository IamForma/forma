# Адаптер codex — бета

Перенесён как есть из прежнего `templates-codex/`. Теста соответствия контракту экономики (`core/manual/en/03-forma/ECONOMY.md`) у него нет, установщик его ставит (бета, `--engines codex`), но проверки соответствия нет, поэтому `sync-engines --check` называет его «не готов» сведением, не нарушением. Готовым его делает отдельная карточка: свой адаптер экономики + тест соответствия по эталону `adapters/claude/scripts/claude-economy.cjs`.
