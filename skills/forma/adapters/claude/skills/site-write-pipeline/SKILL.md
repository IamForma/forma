# Конвейер записи на сайт

Читать вместе с `novamira-wp-deploy` (он первым). Здесь — порядок и обязательные части payload.

## Порядок

1. **Снимок (read-only).** Текущие значения всех единиц в `snapshot.json` карточки. Пишущих вызовов нет.
2. **Проверка дрейфа (read-only).** Копия payload без пишущих вызовов, сверка с снимком. Дрейф по единице — единицу не писать, зафиксировать, остальные продолжать. Повторять, если с снимка прошло заметное время.
3. **Dry-run.** `site-php.cjs payload.php --dry-run --write`: распознан пишущий вызов. Без `--write` пишущий payload отклоняется (exit 2).
4. **Запись (`--write`), один вызов на все единицы.** Внутри payload по каждой единице:
   - дрейф-проверка прямо перед записью;
   - запись;
   - **перечитка** из БД и сравнение с ожидаемым;
   - расхождение → **откат** этой единицы к снимку, статус `rolled_back`;
   - **проверка кириллицы** в записанном поле, если цель — английский (вне защищённых терминов);
   - отчёт по каждой единице: `requested` против `actual`.
5. **Очистка кеша — один раз в конце**, и только если была хотя бы одна реальная запись.
6. **Проверка фронтенда (реальные запросы, не БД).** Каждый затронутый адрес: HTTP 200 без `Fatal error`/`Uncaught`; для слагов — старый адрес 301 на новый; для SEO-полей — title/description в отданном HTML.
7. **Итог в `## Результат`:** числа по статусам (записано / без изменений / дрейф / откат), пути отчётов, расхождения. Откат и дрейф — факты, не стоп всей карточки.

## Правила payload

- Данные встроены литералами: `__DIR__` внутри execute-php указывает на каталог плагина, не на репозиторий.
- Новые адреса читать (`get_permalink`, `get_term_link`), не собирать строкой.
- Идемпотентность: повторный запуск не плодит дубли (редиректы — `skipped_exists`).
- Порядок единиц: родители раньше зависимых (рубрики → метки → записи).
- Пишет один payload; пробы и правки «на лету» вне плана запрещены. Дефект вне карточки возвращается по таблице маршрута.

## Остановка

- Статус `all_drift` — стоп без повтора, снимок устарел.
- Любая единица со статусом `ok` в записи, но не прошедшая шаг 6 — зафиксировать, не чинить на месте.
- Вдвое больше вызовов, чем в бюджете шагов карточки, — остановиться и доложить.
- Вторая подряд одинаковая диагностика — стоп, не третья попытка.

## Предупреждения PHP после очистки кеша

`site-php.cjs` помечает прогон `work` по числу предупреждений. Предупреждения `unlink(...): Is a directory` из nginx-helper — известный класс (файл опыта проекта о nginx-helper, если он есть); не ошибка записи. Если их число выросло — проверить, что исправляющий сниппет опубликован.

## Откат

Каждая карточка хранит `run-NN-rollback-*.php` или значения снимка, из которых откат собирается без угадывания. Откат — отдельным вызовом после решения человека.
