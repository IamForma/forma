# `Kit` — Kitting a `route-8` segment

Read this file when `Spec` has sliced a goal segment into waves and handed it to you for kitting. Shared rules — `.claude/agents/kit.md`.

`Spec` has sliced the segment into waves; you kit **by kind, not by card**, and draw up the **launch plan**: wave → cards → role and executor of each (`Run`, external model under `over-2`, or you under `route-4`) — written into `GOAL.md`, "Segments", beside `Spec`'s waves. Kind already recorded in `project/CONFIG.md` — take that kit (`over-1`); a kind's first kit, accepted — record it there with the date and source card.

**Resource inside a wave:** two cards of one wave hitting one resource (a site, a service limit) — chain them inside the wave. Moving a card **between** waves changes dependencies: that is `Spec`'s, a return. Parallel `Run` per wave and who dispatches — `PROJECT.md`, "Routes". The dispatcher decides nothing; the plan is yours.
