# `run-protocol-adapters`

Profile of `run.md` for one kind of work — the base role's criteria and process apply; this file only narrows the kit.

## When to take

An assembly card over the engine adapters: the contract already exists in `.forma/dashboard/lib/engines.cjs` (`sources`, `spendTag`, capabilities, node-model-effort table, `check <engine>`) and the card moves each real engine folder onto it. Result: each `forma-adapter.cjs` (`.minimax/`, `.agents/`, `.claude/`) declares the contract fields (own `scriptsDir`, `rolesDir`, `packageManifest`); no core file under `.forma/` or `.claude/scripts/` holds a hardcoded `.minimax`/`.agents` path or an `=== 'claude-code'` check outside the Claude adapter; engine roles regenerated by the engine's own generator; spend tags reconciled between adapter and `## History` form; an automatic guard test that creates a temporary `.demo/` engine with a minimal adapter, runs the graph builder and dashboard, deletes it and re-checks exit 0; adapter tests in the engine's `tests/`. Closed by `engines.cjs check <engine>` exit 0 per engine, the guard test, an engine-off rename run of the builder/dashboard/`sync-engines --check`, and a commit in the protocol clone (English, no push).

## Takes / does not take

- **Takes:** «`.minimax/forma-adapter.cjs` declares `packageManifest`, `spendTag`, the node-model-effort table; `engines.cjs check minimax-code` exits 0»; «Gemini adapter owns `.agents/scripts` and `.agents/rolesDir`, the graph builder stops reading `.claude/scripts` for it»; «grep the core for `.minimax`/`.agents` literals and `=== 'claude-code'`, replace each with an adapter walk, zero left»; «regenerate MiniMax roles with `gen-roles.cjs` after new catalog roles»; «a test that makes `.demo/`, runs builder and dashboard, deletes it, re-runs».
- **Does not take:** «add a field to the adapter SHAPE in `engines.cjs`, new checker, the law/contract text» (→ `run-protocol-core`); «dashboard UI, spend-line regex, speed section» (→ `run-protocol-dashboard`); «extend a graph builder as a new feature» (→ `run-protocol-script`); «sync project extensions with engine folders, template/custom sorting» (→ `run-protocol-engine`); «reword a role or skill markdown only» (→ `run-protocol-docs`).

## Boundary

Edit only the files the kit names; the contract fields come from the finished contract, they are not redesigned here (a contract gap is a stop, return to `Kit`). Edits inside `.minimax/` and `.agents/` are allowed only because the card, approved by the human in its parent plan, names them as its subject; any other engine folder or file is out. `AGENTS.md` is not touched. Code stays dependency-free Node, no network or model call. Disabling an engine means a temporary folder rename, restored in the same step, and verified restored (`git status`). The `.demo/` test creates the folder and deletes it; the delete is its own separate command, never in the same command as a protected path (delete-guard hook blocks it) and never by touching the protocol's own files. Every changed project file with a copy in `.forma/protocol` ends byte-identical (`cmp`) or is synced by the kit's exact `engine-to-protocol.cjs` command (list first, then `--add`/`--apply` only for the named file); a conflict there is a stop. No project traces in engine files (prohibition 16). Verify by facts: quote each exit code, the last line of `sync-engines --check` and `check-release --traces`; no «green» without the command's own output. Commit in the clone with explicit paths only, on `dev` (check the branch first), English message with no Cyrillic (prohibition 18), never push, never amend published history. A second identical diagnosis (prohibition 14) is a stop.
