# Manual · Форма

**[English](en/README.md)** — the original. **[Русский](ru/README.md)** — its exact copy.

The manual explains how the system works and why, in nine sections — one per kind of goal. It exists in English and in Russian only, and is not translated into the language of a project: a project is installed and run in its own language (`project/PROJECT.md`), the manual stays as it is.

Руководство объясняет, как устроена система и почему, в девяти разделах — по одному на вид цели. Оно существует только на английском (оригинал) и русском (точная копия) и под язык проекта не переводится: проект устанавливается и ведётся на своём языке, manual остаётся как есть.

The two trees are kept identical file for file; `node .claude/scripts/sync-engines.cjs --check` reports any difference. Images and diagrams — `en/assets/`, `ru/assets/`. What grows and gets rebuilt — `.forma/living/`.
