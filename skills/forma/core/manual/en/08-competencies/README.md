# 8. Competence segments

Code kind: `competencies` · main goal: `project/goals/goal-competencies/GOAL.md`

The roles are the store of experience (`project/experience/`): the history, the experience of what was done, from which the roles are made. Roles are an asset, like the result of the project: they pass into future project templates and so cut `Kit`'s spend. Forming roles is `Kit`'s main task and counts as a task and as reaching a goal.

| | |
|---|---|
| **Who sets the goal** | the core, by default |
| **Route** | `Kit` forms the roles (`route-4`); it builds graphs as cheaply as possible (`kit-graphs.md`) |
| **Who confirms** | `Intent` or the human |
