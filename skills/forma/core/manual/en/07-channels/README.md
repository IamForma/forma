# 7. Production channels

Code of the kind: `channels` · main goal: `project/goals/goal-channels/GOAL.md`

The place where the product itself is made — as the way it is realized, not as the final result. Channels that start production and deliver the product; tasks are predetermined by roles; one board or several; runners (`Run`) work. The main goal `goal-channels` and subgoals `goal-NN` are the parts of the product; `Kit`, using the roles, reproduces the result.

| | |
|---|---|
| **Who forms the goal** | `Intent` derives stages from the end-image, the human adds to it |
| **Route** | by default the full route `route-7`: `Intent` → `Spec` → `Kit` → `Run` → `Intent` → the human → `Core` (`AGENTS.md` §2); each card's route is named by its label |
| **Who confirms** | the task — `Intent`, the cycle — `Core`, the goal is closed by the human |
