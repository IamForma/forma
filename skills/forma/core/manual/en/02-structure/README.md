# 2. Project structure

Card type: `structure` · main goal: `project/goals/goal-structure/GOAL.md`

How the project looks: its items, their order, the roadmap (`ROADMAP.md`). Documentation for the human (`project/docs/`) lives here whole: reading the assembled project shows what the resource was spent on.

| | |
|---|---|
| **Who forms the goal** | `Intent` proposes a structure from the brief, the human supplements and confirms it |
| **Route** | `Intent` holds `in-progress` itself (`route-0`, `route-1`): the documentation is addressed to the human, and `Spec` and `Run` do not address the human (`AGENTS.md` §7) |
| **Who confirms** | only the human — a promise has been given to them |

The documents themselves live in `project/docs/`, not here: the manual explains how this card type is maintained.
