# 9. Goal achievement

Code of the card type: `results` · main goal: `project/goals/goal-results/GOAL.md`

Every project starts here and ends here: it defines what we are after and what the goal of each of the nine sections is; at the end — the check, reached or not. The result image of a goal (`GOAL.md`) belongs here. The format is an ordinary task: what we want, what is needed, reached / not reached; tasks wait in `backlog` for the "verdict", checklists inside a task are allowed. Goals are formed from the interviews of section 6.

| | |
|---|---|
| **Who forms the goal** | **the human** — a single simple sentence is enough |
| **Route** | the addition is written next to the goal; `GOAL.md` is not changed (prohibition 8); only the human turns the addition into a new goal or a re-opening |
| **Who confirms** | the human |

The end-image and the final acceptance may differ — this section keeps the difference visible without rewriting the goal.

Later: a graph of events, agreeing every point with the human, creating new tasks when a goal is not reached.
