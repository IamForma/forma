# 7. Каналы производства

Код вида: `channels` · главная цель: `project/goals/goal-channels/GOAL.md`

Место, где создаётся сам продукт — как способ реализации, а не конечный результат. Каналы запуска производства и доставки продукта; задачи предопределены ролями; можно одна доска или несколько; работают раннеры (`Run`). Главная цель `goal-channels`, подцели `goal-NN` — части продукта; `Kit`, используя роли, воспроизводит результат.

| | |
|---|---|
| **Кто формирует цель** | `Intent` выводит этапы из образа результата, человек дополняет |
| **Маршрут** | по умолчанию полный маршрут `route-7`: `Intent` → `Spec` → `Kit` → `Run` → `Intent` → человек → `Core` (`AGENTS.md` §2); маршрут каждой карточки называет её метка |
| **Кто подтверждает** | задачу — `Intent`, круг — `Core`, цель закрывает человек |
