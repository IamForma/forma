# 9. Достижение целей

Код вида: `results` · главная цель: `project/goals/goal-results/GOAL.md`

С него начинается каждый проект и им же заканчивается: определяет, к чему стремимся и какова цель каждого из девяти разделов; в конце — сверка, достигли или нет. Образ результата цели (`GOAL.md`) идёт сюда. Формат — обычная задача: чего хотим, что надо, достигли / не достигли; задачи висят в `backlog` и ждут «приговора», допустимы чек-листы внутри задачи. Цели формируются из интервью раздела 6.

| | |
|---|---|
| **Кто формирует цель** | **человек** — достаточно одного простого предложения |
| **Маршрут** | дополнение пишется рядом с целью; `GOAL.md` не меняется (запрет 8); только человек превращает дополнение в новую цель или переоткрытие |
| **Кто подтверждает** | человек |

Образ результата и конечная приёмка могут отличаться — этот раздел держит разницу видимой, не переписывая цель.

Позже: граф событий, согласование с человеком по каждому пункту, создание новых задач при недостижении.
