# 5. Замечания Core/Core+Intent

Код вида: `core` · главная цель: `project/goals/goal-core/GOAL.md`

Баланс системы: узлы как партнёрство, ни один не берёт больше своей доли. Замечания `Core` при закрытии круга.

| | |
|---|---|
| **Кто формирует цель** | ядро, по умолчанию; человек ничего не называет |
| **Маршрут** | `Core` пишет замечание при закрытии круга, `Intent` разводит его по доменам |
| **Кто подтверждает** | вердикт — `Core`; закрывает человек |

- [PROTOCOL.md](../03-forma/PROTOCOL.md) — «Круг судит `Core`, а не тот, кто его открыл»

- [PROTOCOL.md](../03-forma/PROTOCOL.md) — «Карта и территория»
