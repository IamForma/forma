# 1. Ценность/Intent+Kit

Код вида: `value` · главная цель: `project/goals/goal-value/GOAL.md`

Ценность проекта: во что обходится производство — токены, кэш-чтение, заходы, цена круга.

| | |
|---|---|
| **Кто формирует цель** | ядро, по умолчанию: экономика как она есть — цена не задаётся заранее, а записывается по мере работы |
| **Маршрут** | `Intent` → `Spec` → `Kit` → `Run` → `Intent`; замечание по расходу пишет `Core` при закрытии круга |
| **Кто подтверждает** | вердикт — `Core`, закрывает цель человек |
