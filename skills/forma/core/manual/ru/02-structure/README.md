# 2. Структура проекта

Код вида: `structure` · главная цель: `project/goals/goal-structure/GOAL.md`

Как проект выглядит: пункты, последовательность, дорожная карта (`ROADMAP.md`). Документация для человека (`project/docs/`) — целиком здесь: прочитав собранный проект, видно, на что потрачен ресурс.

| | |
|---|---|
| **Кто формирует цель** | `Intent` предлагает структуру по брифу, человек дополняет и подтверждает |
| **Маршрут** | `Intent` держит `in-progress` сам (`route-0`, `route-1`): документация обращена к человеку, `Spec` и `Run` к человеку не обращаются (`AGENTS.md` §7) |
| **Кто подтверждает** | только человек — ему дано обещание |

Сами документы живут в `project/docs/`, не здесь: manual объясняет, как этот вид ведётся.
