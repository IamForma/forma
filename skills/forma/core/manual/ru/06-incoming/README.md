# 6. Входящие/Intent

Код вида: `incoming` · главная цель: `project/goals/goal-incoming/GOAL.md`

Задача, которую человек даёт `Intent` по ходу работы, называя её цель.

| | |
|---|---|
| **Кто формирует цель** | ядро, по умолчанию: как есть на деле, не предусматривается |
| **Маршрут** | `Intent` решает сам (держит `in-progress`) либо отправляет в маршрут её вида — для вида 7 это `Spec`; метка цели сохраняется (`AGENTS.md` §7) |
| **Кто подтверждает** | решил `Intent` — принимает только человек (запрет 1) |

Сюда же попадают карточка без нарезки и дефект вне текущей цели.
