# 8. Сегменты компетенций

Код вида: `competencies` · главная цель: `project/goals/goal-competencies/GOAL.md`

Роли — это и есть хранилище опыта (`project/experience/`): история, опыт «что делали», из него составлены роли. Роли — актив, как результат проекта: их передают в будущие шаблоны проекта и тем сокращают расходы на `Kit`. Формирование ролей — основная задача `Kit`, считающаяся задачей и достижением цели.

| | |
|---|---|
| **Кто формирует цель** | ядро, по умолчанию |
| **Маршрут** | роли формирует `Kit` (`route-4`); графы строит как можно дешевле (`kit-graphs.md`) |
| **Кто подтверждает** | `Intent` или человек |

## Почему так — где объяснено

- [PROTOCOL.md](../03-protocol/PROTOCOL.md) — «Память проекта»
- [PROTOCOL.md](../03-protocol/PROTOCOL.md) — «Умение — это скилл среды»
- [PROTOCOL.md](../03-protocol/PROTOCOL.md) — «Справочники»

Динамика — графы, журнал изменений, словарь — в `.forma/living/`; хранилище опыта — `project/experience/`.

**Не путать.** «Сегменты компетенций» — раздел 8, хранилище опыта и ролей. «Сегмент цели» (`route-8`, метки `seg-N`, `wave-N`) — единица нарезки цели на работу (`GOAL.md`, «Сегменты»). Общее у них только слово: метка `seg-N` не относит карточку к разделу 8.
