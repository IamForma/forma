# 2. Документация/Intent

Код вида: `docs` · главная цель: `project/goals/goal-docs/GOAL.md`

Документация самого продукта для людей: пользовательская, для администраторов, техническая — как работать с тем, что производим.

| | |
|---|---|
| **Кто формирует цель** | `Intent` предлагает структуру по брифу, человек дополняет и подтверждает |
| **Маршрут** | `Intent` держит `in-progress` сам: документация обращена к человеку, `Spec` и `Run` к человеку не обращаются (`AGENTS.md` §7) |
| **Кто подтверждает** | только человек — ему дано обещание |

Сами документы живут в `project/docs/`, не здесь: manual объясняет, как этот вид ведётся.
