# Чертёж пяти узлов

Диаграмма маршрута: `.forma/manual/ru/assets/five-nodes.excalidraw` (плюс статичный `five-nodes-console.html`).

Полная таблица «куда при отклонении» не дублируется здесь — она в `AGENTS.md`, разд. 1. Ниже — то, чего в `AGENTS.md`/`SCHEME.md`/`PROTOCOL.md` ещё не было в виде готовой сводки.

## Владение файлами — сверено по ролям агентов

| Узел | Пишет |
|---|---|
| Intent | brief/interview.md, brief/reference.md · GOAL.md · JOURNAL.md (хвост «Чего не хватало») · VARS/ · ROADMAP.md · история карточки — итог сверки |
| Spec | карточка — верх (.devtool/features/) · история карточки — записи передела |
| Kit | карточка — низ · история карточки — расхождение и правка · .claude/skills/<имя>/SKILL.md |
| Run | project/docs/ · .claude/scratch/ или .agents/scratch/ (по движку) |
| Core | GOAL.md — вердикт, таблица кругов · PROJECT.md → «Пороги» (только через остановку) |

## Ревизия 1

Из таблицы владения файлами (`.forma/manual/ru/03-forma/SCHEME.md`, разд. 6) удалена строка «CHECK.md | Intent, Core | никогда»: она называла только двух из четырёх реальных авторов файла. Роли `spec.md` и `kit.md` прямо предписывают им самим писать в `CHECK.md` при переделе и возврате — подтверждено в `.forma/manual/ru/03-forma/PROTOCOL.md`, разд. «Возврат как отдельная работа».

## Ревизия 2

Отдельный `CHECK.md` упразднён. История задачи переехала в саму карточку — третьей зоной, рядом с верхом (`Spec`) и низом (`Kit`); дописывают `Spec`/`Kit`/`Intent`, каждый своей строкой на своём событии. Причина: карточка и её `CHECK.md` жили в разных, не связанных друг с другом деревьях каталогов (доска — плоско по статусу, `CHECK.md` — вложенно по цели/кругу), и это была единственная настоящая причина «искать в двух местах», не сам факт разделения контента. Единственное, что было по-настоящему уровня круга, а не задачи, — вердикт `Core` — переехало в уже существующую таблицу кругов `GOAL.md`, а не осталось в отдельном файле.
