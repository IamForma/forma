Код вида: `forma` · главная цель: `project/goals/goal-forma/GOAL.md`

Движок и механика задачи: пять узлов, снаряжение, исполнение, проверка, возврат, передача, язык схемы.

| | |
|---|---|
| **Кто формирует цель** | ядро, по умолчанию: движок, собранный из того, что есть, — донастраивается по ходу |

| **Кто подтверждает** | `Intent` или человек; работу `Intent` — только человек |

## Демонстрационный круг

Свежему проекту (ворота старта закрыты, доска пуста) в первой сессии один раз предлагается короткая демонстрация всего маршрута на двух небольших карточках. Человек отвечает **начать**, **пропустить** или **позже**; ответ хранится в `project/config/DEMO` (`none`, `declined`, `later:<n>`, `done`), поэтому спрашивают один раз. Карточки демо несут метку `demo`: это единственные карточки, допустимые при закрытых воротах, они не попадают в расход и статистику дашборда, а демо заканчивается таблицей по узлам (заходы, токены, время) и уборкой — удалить или оставить. Процедура: `intent-demo.md`.
