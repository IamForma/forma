# 4. Ресурсы проекта

Код вида: `resources` · главная цель: `project/goals/goal-resources/GOAL.md`

Всё необходимое, чтобы реализовать проект: референсы, активы, изображения, идеи, промпты — ресурсная часть, «надеваемая» на структуру. Интервью отсюда перенесены в раздел 6.

| | |
|---|---|
| **Кто формирует цель** | **человек**, по брифу; `Intent` не набрасывает за него |
| **Маршрут** | ресурсы собирает `Intent` вместе с человеком; маршрут называет метка карточки; бриф — точка опоры, не переписывается без слова человека (`AGENTS.md` §1) |
| **Кто подтверждает** | человек |
