# 1. Аналитика проекта

Код вида: `analytics` · главная цель: `project/goals/goal-analytics/GOAL.md`

Статистика расходов и движения токенов во времени; все учитываемые ресурсы; задачи по экономике проекта. Строки расхода и дашборд «Экономика» остаются в ведении `Intent` и `Core`. Позже сюда придёт статистика результативности опыта — достигли или не достигли.

| | |
|---|---|
| **Кто формирует цель** | ядро, по умолчанию: экономика как она есть — цена не задаётся заранее, а записывается по мере работы |
| **Маршрут** | маршрут каждой задачи называет её метка `route-N`; замечание по расходу пишет `Core` при закрытии круга |
| **Кто подтверждает** | вердикт — `Core`, закрывает цель человек |
