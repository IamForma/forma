# 5. Эффективность формы

Код вида: `efficiency` · главная цель: `project/goals/goal-efficiency/GOAL.md`

Центр, «ядро»: ошибки, баланс узлов, их эффективная работа, сбалансированность системы; эффективность взаимодействия узлов — партнёрство. Цель — понять, насколько проект эффективен; главное — сохранить баланс сил.

| | |
|---|---|
| **Кто формирует цель** | ядро, по умолчанию; человек ничего не называет |
| **Маршрут** | `Core` пишет замечание при закрытии круга, `Intent` разводит его по доменам |
| **Кто подтверждает** | вердикт — `Core`; закрывает человек |
