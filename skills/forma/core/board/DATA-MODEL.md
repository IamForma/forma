# Модель данных доски

Доска — папка `.devtool/features/`, одна карточка — один файл `card-NNN-<slug>.md`. Формат совместим с расширением `kanban-markdown`: оно переписывает фронтматтер фиксированным набором ключей и стирает любой другой — поэтому метки маршрута живут в `labels`, а не в своих ключах.

## Фронтматтер — ровно эти ключи

| Ключ | Значение |
|---|---|
| `id` | имя файла без `.md` |
| `status` | `backlog` · `todo` · `in-progress` · `review` · `done` |
| `priority` | `low` · `medium` · `high` |
| `assignee` | `"Spec"` · `"Kit"` · `"Run"` · `"Intent"` · `"Core"` · `null` (AGENTS.md §7) |
| `epic` | точное имя эпика из `project/config/PROJECT.md`, «Эпики проекта» |
| `dueDate` | дата или `null` |
| `created`, `modified` | ISO-время |
| `completedAt` | ISO-время или `null` |
| `labels` | ровно одна метка цели (`goal-NN` / `goal-<код>`) + метки маршрута (`route-N`, `over-N`, `seg-N`, `wave-N`, `after-card-NNN`, `trial`) — AGENTS.md §6 |
| `order` | строка порядка в колонке |

## Тело

Заголовок `# card-NNN · <название>`, затем четыре зоны по порядку: задача · снаряжение · история · результат (на языке проекта, AGENTS.md §6).

## Движение

`status: done` — файл переезжает в `.devtool/features/done/`, обратно — из неё. Переносит расширение доски; без него — тот, кто меняет статус.

## Инструменты ядра

- `.forma/board/new-card.cjs` — создать карточку (номер, эпик, метки, зоны), сразу проверить.
- `.forma/board/check-board.cjs [<card-id>]` — проверка доски; выход 1 при нарушениях. Движок вызывает её из своей сверки и из хука записи карточки.
