# Словарь: `.claude/agents/on-demand/run-external-model.md`

Уровень 2b. Английский оригинал — `.claude/agents/on-demand/run-external-model.md`. Gemini-зеркало — `.agents/plugins/forma/agents/on-demand/run-external-model.md` (`living/dictionary/gemini-on-demand-run-external-model.md`).

## Что это

Файл «по требованию» для `Run`: читается только когда снаряжение конкретной карточки назначает внешний канал исполнения — мост `external-model-bridge.cjs` (DeepSeek/OpenRouter), не обычный Agent tool. Самый короткий файл во всей схеме — два абзаца — потому что описывает узкое техническое исключение из общего правила «расход пишет вызывающий».

## Зачем это

В `CLAUDE.md` §3 закреплено общее правило: строку о заходе (токены, время, деньги) пишет вызывающий узел, не сам исполнитель, — потому что обычно у изолированного вызова Agent tool физически нет доступа к собственным метаданным расхода изнутри, а у того, кто его вызвал, есть. Мост-вызов через `Bash` ломает эту схему: вызывающего снаружи нет вообще, мост дёргается напрямую из `Run`. Файл фиксирует единственное явное исключение из «пишет вызывающий» — и подчёркивает, что это не нарушение запрета 1 («работу подтверждает только принимающий узел»), а осознанный частный случай, потому что здесь просто больше некому.

## Как это работает

Два правила:

1. **Кто выбирает канал** — не `Run`. Решает `Kit` на снаряжении: внешний канал назначается только для задач без нужды в живом доступе к среде (чистый текст — черновик, формулировка, разбор без MCP/файловых операций), потому что мост текст-в-текст живого доступа не даёт в принципе. `Run` смотрит назначенный канал в снаряжении карточки и не подменяет его по своему усмотрению.
2. **Кто пишет строку расхода** — сам `Run`, сразу после ответа моста, не откладывая, и берёт числа из самого ответа (`cost_usd_estimate`, `duration_ms`, `usage.total_tokens`), а не оценивает на глаз — тот же принцип «расход по факту, не по впечатлению», что и в общем правиле `CLAUDE.md`, просто применённый узлом, у которого в этом одном случае нет вызывающего снаружи.
