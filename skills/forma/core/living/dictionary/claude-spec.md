# Словарь: `.claude/agents/spec.md`

Уровень 2. Английский оригинал — `.claude/agents/spec.md`. Gemini-зеркало — `.agents/plugins/forma/agents/spec.md` (`living/dictionary/gemini-spec.md`).

## Что это

Ролевой файл узла `Spec` — того, кто режет целое (`GOAL.md`) на отдельные карточки задач. Вызывается изолированным заходом Agent tool, без памяти между вызовами: видит только кэш круга. Единственный из пяти узлов, у кого во фронтматтере нет доступа к сети/сайту вообще — только чтение и запись файлов плюс два узких `Bash`-моста (подсчёт статистики и извлечение для графа знаний).

## Зачем это

Между образом результата (`Intent`) и снаряжением конкретной задачи (`Kit`) должен стоять узел, который переводит целое в связные, проверяемые части — и именно на этом переходе рождается самая частая потеря схемы: фрагментация, когда части понятны сами по себе, но связи между ними выпали. `spec.md` — единственное место, где подробно расписано, как резать так, чтобы этого не происходило: три правила нарезки (одна квалификация на карточку, покрытие входа между соседними карточками, обязательная сборка как отдельная карточка), плюс отдельные протоколы для содержательных карточек, пилотных запусков серии и разбора уже сделанного.

## Как это работает

- **«Нарезка»** — базовые механики: откуда брать величины (`VARS/` по ссылке `[[имя]]`, не по значению), как называть файлы карточек (короткий предметный слаг, не транслитерация и не закодированный путь), когда доработка закрытой карточки сливается в тот же круг, а когда становится суб-задачей с `parent`.
- **«Три правила нарезки»** — ядро дисциплины: одна квалификация, покрытие входа, сборка отдельной карточкой.
- **«Контент, а не макет»** — правило для карточек, создающих content-единицы (посты, демо): признак готовности должен требовать реального контента (изображение, галерея нужного размера), не пустого каркаса.
- **«Пробный запуск»** — три-пять задач проходят полный путь до передачи всей пачки, а для серии однотипных сущностей — специальный случай «пилота», единственной задачи первого круга, доводимой до полноты новыми раундами той же карточки, а не пересозданием.
- **«Недостижимая величина»** и **«Через границу круга»** — что делать, когда `Kit` эскалировал ограничение среды, и как задача переживает границу между кругами одной цели (продолжается той же карточкой) в отличие от границы между целями (создаётся заново, со ссылкой на предыдущую версию).
- **«Внешняя модель — только извлечение, не нарезка»** — узкий, отдельно проверенный контракт: сама нарезка всегда идёт внутренней моделью, внешний мост разрешён только для извлечения под граф знаний (`graphify`), спутать эти два применения запрещено явно.

Критерий приёмки — «просто» (карточка читается без объяснений) в паре с «совершенно» (нарезка полна, ничего не выпало) — вторая половина пары защищает от соблазна добиться простоты выбрасыванием связей.
