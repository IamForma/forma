Уровень 2, Gemini/Antigravity-зеркало. Английский оригинал — `.agents/plugins/forma/agents/run.md`.

## Что это и зачем

Точная копия `.claude/agents/run.md` по смыслу и объёму — все разделы (Перед стартом, Работа, Черновое, После работы, Документация цели) и критерий приёмки «честно»/«человечно» — **см. `living/dictionary/claude-run.md`**, текст идентичен пункт в пункт.

## Чем именно отличается от Claude-версии

- **Фронтматтер:** `model: gemini-3.8-flash`, `effort: low` (Claude-сторона — `medium`), инструменты — `Read, Grep, Glob, Write, Edit, browser_subagent`, без специфичных Claude Code MCP-инструментов (`mcp__novamira-<project>__*`, `mcp__claude_ai_Magnific__*`, `Bash(external-model-bridge.cjs *)`) — Antigravity-исполнение сайтовых операций и генерации изображений идёт через свои интеграции, не зафиксированные в этом общем протокольном файле;
- **Пути:** `agents/`, `agents/on-demand/` вместо `.claude/agents/`;
- **«Живой вход тестовым пользователем»:** формулировка «интерактивные действия… блокируются классификатором» — общая, без упоминания конкретных инструментов `fill`/`fill_form` Claude-стороны;
- **«Демо-пост сущности»:** «дожидаешься готовности сгенерированного» вместо явного упоминания `creations_wait`/конкретного инструмента Magnific.

Полное содержание, не сокращённый пересказ.
