# Словарь: `.agents/rules/gemini-8.md`

Уровень 1. Английский оригинал — `.agents/rules/gemini-8.md`.

## Что это

Корневой файл проекта для движка Google Antigravity — и, как и `CLAUDE.md`, **не свод правил**. Правила в `AGENTS.md` ([словарная статья](AGENTS.md.md)). Этот файл — строка `@AGENTS.md` плюс §8 «Engine architecture in Antigravity».

Раньше он был «полной копией `CLAUDE.md` по смыслу и объёму» — двумя текстами об одном законе, которые приходилось удерживать вместе скриптом сверки. Копии больше нет: текст один физически.

## Зачем это

Antigravity читает `AGENTS.md` нативно, так что формально обёртка не обязательна. Но §8 всё равно нужна: у этой среды своё устройство, и оно заметно сложнее, чем у Claude Code, — два режима работы вместо одного.

## Как это работает

- **где роли** — `.agents/plugins/forma/` (манифест `plugin.json` и промпты в `agents/`, включая слой `agents/on-demand/`). Это каталог ролей, на который §1–7 ссылаются голыми именами файлов;
- **модели узлов** — отдельная таблица в §8. Какая модель под каким узлом — дело движка, а не закона: пять пар из §1 верны при любом исполнителе;
- **как вызывается узел** — зависит от режима сессии. В режиме Teamwork доступны `define_subagent`/`invoke_subagent`: `Intent` регистрирует четыре роли на лету и дальше раздаёт задачи, каждая в изолированном контексте без родительской памяти — запреты 1 и 7 обеспечены физически. В обычной быстрой сессии этих инструментов нет, изоляции нет тоже; тогда узел обязан сразу сказать об этом человеку и работать в вырожденном режиме с явными метками стадий, допустимом только для мелких задач с бюджетом в один заход;
- **откуда берётся расход** — **не установлено**. §3 требует три числа с каждого захода, читаемых из результата вызова. Какие поля возврата `invoke_subagent` их несут — здесь не проверено, а имена полей Claude Code (`<usage>`, `subagent_tokens`, `duration_ms`, `cache_read_input_tokens`) в Antigravity **недействительны**: они принадлежат другому API и попали в этот файл прежней синхронизацией по ошибке. Пока величины не установлены разведкой, вызывающий узел на этом движке пишет строку истории с теми полями, которые реально может подтвердить, и прямо называет недостающие недостающими — не выдумывает число и не роняет строку молча;
- **где настройки** — MCP в `.agents/mcp_config.json`, общие умения в `.agents/skills/`.

Русское пояснение к самим правилам — [`AGENTS.md.md`](AGENTS.md.md) и `manual/ru/03-forma/PROTOCOL.md`.
