# Словарь: `.claude/agents/run.md`

Уровень 2. Английский оригинал — `.claude/agents/run.md`. Gemini-зеркало — `.agents/plugins/forma/agents/run.md` (`living/dictionary/gemini-run.md`).

## Что это

Ролевой файл узла `Run` — единственного исполнителя схемы, который реально трогает сайт/продукт. Делает ровно заданное выданными умениями, ничего сверх и ничего вместо. Намеренно не получает `AskUserQuestion` в инструментах — это memoryless-конструкция: у `Run` нет памяти между заходами, и разговор с человеком, начатый и забытый на середине, потерял бы ответ безвозвратно; препятствия идут не в диалог, а возвратом к `Kit`.

## Зачем это

`Run` — самое узкое место цепи: он не может пропустить (задача перед ним), не может исказить (способ назвали), и единственное, что ему остаётся при столкновении с пробелом, — подставить похожее. Файл прямо называет это «твоя потеря — подмена» и формулирует главное защитное правило схемы для этого узла: пробел — это возврат к `Kit`, а не место для догадки, ни при каких обстоятельствах не «выкручивайся сам».

## Как это работает

- **«Перед стартом — проверка формы»** — пять обязательных пунктов (результат, признак готовности, доступы/данные/инструмент, бюджет заходов, куда идёт дальше), без которых `Run` не начинает вообще; недостающий возвращается в `Kit` с точным указанием, какого пункта нет.
- **«Работа»** — набор жёстких правил: пользоваться только выданным умением (не тем, что случайно сработало по совпадению описания); сначала проверить `project/docs/` на предмет уже сделанного похожего разбора; подставлять значения `VARS/` по имени `[[...]]`, не своим; не добывать ничего самому при нехватке инструмента или данных.
- **«Черновое»** — что можно временно класть в `scratch/<задача>/` (стирается при закрытии круга), и два случая, когда черновик перестаёт быть черновиком: повторно используемый скрипт (оформляется умением) и скриншот, на который сослалась сверка (переезжает в «Результат» или `docs/`).
- **«После работы»** — детальная инструкция по разделу «Результат»: рабочая ссылка markdown-синтаксисом на каждый пункт признака, никогда не голый id; пароли/токены — только по ссылке на `VARS/credentials.md`, никогда значением; отдельно — когда задача рода «дело» получает короткую запись в `project/docs/` (четвёртая дверь к человеку, переживающая закрытие цели).
- **«Документация цели»** — особый тип карточки-сборки: `Run` читает только «Результат» и записи `docs/` перечисленных карточек цели, не всю их историю, и сводит это в одну согласованную запись.

Критерий приёмки — «честно» («готово» значит сделанное, а не «я закончил») в паре с «человечно» (расхождение называется раньше, чем на него наткнётся следующий) — без второй половины честность вырождается в формальность «сделал ровно сказанное, а что дальше — не моя забота».
