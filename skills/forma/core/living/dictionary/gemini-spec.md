# Словарь: `.agents/plugins/forma/agents/spec.md`

Уровень 2, Gemini/Antigravity-зеркало. Английский оригинал — `.agents/plugins/forma/agents/spec.md`.

## Что это и зачем

Точная копия `.claude/agents/spec.md` по смыслу и объёму — все разделы (Нарезка, Три правила нарезки, Контент а не макет, Пробный запуск, Недостижимая величина, Через границу круга, Оснастные задачи, Переделы, Внешняя модель) и критерий приёмки «просто»/«совершенно» — **см. `living/dictionary/claude-spec.md`**, текст идентичен пункт в пункт.

## Чем именно отличается от Claude-версии

- **Фронтматтер:** `model: gemini-3.1-pro`, инструменты — `Read, Grep, Glob, Write, Edit`, без `Bash`-мостов (у Claude Code `Spec` держит два узких `Bash`-инструмента — подсчёт статистики `tally.cjs` и извлечение под граф знаний `external-model-bridge.cjs`; у Antigravity внешний канал описан абстрактно, без конкретного скрипта, инструментов Bash во фронтматтере нет вовсе);
- **Пути:** `agents/`, `agents/on-demand/` вместо `.claude/agents/`, `.claude/agents/on-demand/`;
- **Раздел «Внешняя модель»:** формулировка более общая («внешний канал» вместо конкретного `external-model-bridge.cjs`/`Bash`-вызова) — конкретная реализация моста Antigravity-стороны не завязана на тот же Node-скрипт, что у Claude Code;
- **Раздел «Статистика»:** вместо явного упоминания инструмента `tally.cjs` — общая формулировка «разбирая строки расхода из истории карточек цели», без привязки к конкретному скрипту.

Полное содержание, не сокращённый пересказ — тот же принцип, что и у `gemini-intent.md`.
