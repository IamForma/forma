# Словарь: `CLAUDE.md`

Уровень 1. Английский оригинал — `CLAUDE.md`.

## Что это

Корневой файл проекта для движка Claude Code — и **не свод правил**. Правила живут в `AGENTS.md` ([словарная статья](AGENTS.md.md)), одним файлом на все среды. Этот файл состоит ровно из двух частей:

1. строка `@AGENTS.md` — импорт закона протокола, §1–7;
2. §8 «Engine architecture in Claude Code» — то, что верно про Claude Code и неверно ни про какой другой движок.

## Зачем это

Две причины, обе практические.

**Первая — импорт надёжнее прямого чтения.** Claude Code умеет читать `AGENTS.md` сам, но только начиная с версии 2.1.277, только когда рядом нет `CLAUDE.md`, и не во всех сессиях (на Amazon Bedrock и при отключённой телеметрии — не умеет). Строка `@AGENTS.md` снимает все три условия разом: правила приходят одинаково в любой сессии и любой версии. Двойной загрузки не бывает — импортированный файл не читается повторно.

**Вторая — движку есть что сказать о себе, и этому нужно место.** Где лежат роли, как вызывается субагент, из каких полей читается расход — это не закон протокола, но узлу без этого не обойтись. §8 и есть такое место: отдельное, не смешанное с общим текстом.

## Как это работает

§8 отвечает на четыре вопроса, которые §1–7 намеренно оставляют открытыми:

- **где роли** — `.claude/agents/*.md` и `.claude/agents/on-demand/*.md`. Это и есть «каталог ролей», на который §1–7 ссылаются голыми именами файлов (`kit.md`, `spec.md`, `intent-goal-opening.md`);
- **как вызывается узел** — родным инструментом `Agent` (`subagent_type`);
- **откуда берётся расход** (требование §3) — из результата самого вызова, блок `<usage>`: токены в `subagent_tokens`, длительность в `duration_ms` (миллисекунды, §3 просит целые секунды), кэш-чтение в `cache_read_input_tokens`. Читаются напрямую из возврата, без второго вызова и без прикидки на глаз;
- **где настройки** — MCP в `.claude/.mcp.json` и `.mcp.json`, хуки в `.claude/settings.json` (`guard-delete.sh` — тот самый страж удаления из §1, и `check-ready.sh`).

**Чего в этом файле быть не должно.** Любой части §1–7, даже короткой цитаты «чтобы было под рукой». Это ровно то, от чего конструкция уходила: два источника правды у одной схемы, расходящиеся молча. Проверяется машинно — `node .claude/scripts/sync-engines.cjs --check` падает, если файл потерял импорт или завёл свою копию правил.

Русское пояснение к самим правилам — [`AGENTS.md.md`](AGENTS.md.md) и `manual/ru/03-forma/PROTOCOL.md`.
