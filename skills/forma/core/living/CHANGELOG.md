# Журнал протокола «Форма»

Что изменилось на уровне Движка (`AGENTS.md`, `manual/`, `.claude/agents/`) и что каждое изменение чинит. Запись держит дату решения; новые — сверху.

- **Unreleased** — **First install adopts what is already in the project root.**
  **What was done.** New `scripts/layout/adopt-existing.cjs` and the installer flags `--adopt` / `--no-adopt`: on the first install (no `.forma/install-manifest.json`, no old layout) every folder and file of the root moves into `project/source/` except the protocol's own files, Git's (`.git*`) and `.env*` — the root keeps nothing else (README, LICENSE, `package.json`, `node_modules`, editor settings and a root `CLAUDE.md` move too). A taken name gets a suffix; an existing `project/` is not entered. Planned before the core is copied, applied after it, so the scaffold still arrives. Dry run by default in the script, journal in `.forma/living/migrations/`, `--rollback`. Without a flag the installer asks in a terminal and skips otherwise. Test: `test/adopt-existing.test.cjs`.
  **What is left.** Relative paths inside the moved content are not rewritten. The release number is set when the protocol is released.

- **Unreleased** — **The nine goal kinds are renamed by function, and a route belongs to the card, not to the epic.**
  **What was done.** Codes: `analytics`, `structure`, `protocol`, `resources`, `efficiency`, `discussion`, `channels`, `competencies`, `results` (were `value`, `docs`, `forma`, `resources`, `core`, `incoming`, `goal`, `experience`, `results`); epics "1. Project analytics" … "9. Goal achievement"; manual folders `01-analytics` … `09-results`; main goals `goal-<code>`. The epic table in `PROJECT.md` lost its route column and the `/Intent+Kit` marker is gone: the short route is the card's label `route-4` (`card-move.cjs` reads the holder of `in-progress` from `route-N`). "Competence segments" (epic 8) and a goal's `seg-N` segments are told apart in `AGENTS.md` §6. `grilling` and `synthesis` live in epic 6. New: `scripts/layout/epics-migrate-install.cjs` with its data file — the installer runs it once on a project that still has the old codes (journal with the original bytes in `.forma/living/migrations/`, rollback by `--rollback`; a project with both old and new codes is a stop).
  **What is left.** Codex and Gemini adapter roles follow the new wording only through the protocol update, not by hand in a project. The release number is set when the protocol is released.

- **0.4.175** — **Установщик и синхронизация клона переведены на раскладку `.forma/`.**
  **Что сделано.** `bin/forma.cjs`: ядро (`manual/`, `board/`, `skills/`, `dashboard/`, `living/`) кладётся под `.forma/` проекта, не в корень; `.gitignore` правит `.forma/dashboard/.cache/`. `scripts/engine-to-protocol.cjs`: карта путей переведена на `.forma/dashboard`, `.forma/manual`, `.forma/skills`, `.forma/board` ядра. Попутно исправлены два дефекта, блокировавшие `npm test`: заниженный `maxBuffer` у `spawnSync` в тестовом хелпере (вывод сборки данных вырос и валил процесс по `SIGTERM`), и два места (`dashboard-view.cjs`, `build-kit-graphs.cjs`), где прежний автоматический перенос ошибочно превратил буквальный путь `.claude/skills` в `.claude/skills`.
  **Что осталось.** Решение о выпуске версии — за человеком.
