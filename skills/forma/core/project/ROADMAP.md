## Карта

Узел карты — цель. Первый уровень — девять главных целей по видам (`goal-<код>`), все идут параллельно; под ними подцели `goal-NN` со сквозными номерами. Вложенность показывает, из чего состоит целое, и задаёт вид подцели (`sync-engines` читает его отсюда). Номер и состояние стоят в строке.

```
<Целое>
├── goal-value · Ценность открыта
├── goal-docs · Документация открыта
├── goal-forma · Форма открыта
├── goal-result-image · Образ результата открыта
├── goal-core · Баланс открыта
├── goal-incoming · Входящие открыта
├── goal-goal · Производство открыта
│   └── goal-01 · <имя части продукта> не начата
├── goal-experience · Опыт открыта
└── goal-review-image · Ревью образа открыта
```

Состояние: `не начата` · `открыта` · `достигнута` · `закрыта` · `отложена`.

**Два разных слова для двух разных событий, не путать.** `достигнута` — локальное состояние одной цели: весь признак цели выполнен по всем кругам серии, и человек явно подтвердил это (`AGENTS.md`, запрет 8) — не автоматически по одному лишь вердикту `Core` «дошли» на уровне отдельного круга внутри `GOAL.md`. `закрыта` — другое, более широкое событие, решение о котором (по одной цели или разом для всего проекта) делает человек отдельно и записывает его сюда же. Цель, пока не подтверждена человеком, остаётся `открыта`, даже если её признак выполнен кругами — «дошли» на круге ≠ «достигнута» цель. Переоткрыть уже `достигнутую` цель новым кругом может только человек.
