# VALUE — статистика и ценность

Заполняет `Spec` при закрытии каждой цели (зовёт `Intent`, `intent-cycle-closing.md`, «After the verdict» — тем же порядком, каким он же зовёт `Kit` на сводку `Конфига`). Один и тот же акт, что и «Что дали закрытые цели» в `ROADMAP.md`, но с другой стороны: там `Intent` пишет качественный итог (что цель дала целому), здесь `Spec` — количественный (что она стоила и из чего собран результат). Не путать с `JOURNAL.md`: там факты каждого захода, здесь — сводка по цели целиком, годная на будущее.

Источник — истории карточек цели и её `GOAL.md`, не собственная оценка на глаз: заходы и токены уже посчитаны и записаны туда узлами, вызывавшими друг друга (`CLAUDE.md`, раздел 3).
