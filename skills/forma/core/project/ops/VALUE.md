# VALUE — statistics and value

Filled in by `Spec` when each goal closes (called by `Intent`, `intent-cycle-closing.md`, "After the verdict" — in the same order in which it also calls `Kit` for the `Config` summary). The same act as "What closed goals gave" in `ROADMAP.md`, but from the other side: there `Intent` writes the qualitative result (what the goal gave the whole), here `Spec` the quantitative one (what it cost and what the result is assembled from). Not to be confused with `JOURNAL.md`: there are the facts of each attempt, here a summary per goal as a whole, fit for the future.

The source is the histories of the goal's cards and its `GOAL.md`, not an estimate by eye: attempts and tokens are already counted and written there by the nodes that called each other (`AGENTS.md`, section 3).
