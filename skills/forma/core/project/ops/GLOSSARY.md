# Glossary

Terms of the project's subject domain — what a thing *is*, one or two sentences, no implementation (`AGENTS.md` §6). Written by `Intent` as soon as a term is drawn out, not in a batch. For a disputed word — choose one, the others go under _Avoid_. The format comes from [mattpocock/skills, `domain-modeling/CONTEXT-FORMAT.md`](https://github.com/mattpocock/skills/tree/main/skills/engineering/domain-modeling), adapted.

Line format:

```md
**Term**:
What it is, one or two sentences.
_Avoid_: synonym, synonym
```
