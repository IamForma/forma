# Project route

**The route defines what kind of project this is.** Not the stack and not a set of tools: the sequence of steps is the project template. This file is the **reference for the fifth interview position** ("naturalness"): `Intent` uses it to check by what natural way the idea is realized.

**Not to be confused with its neighbors.** `ROADMAP.md` — what goals the project has. `SETUP.md` — the install checklist. **`ROUTE.md` — how the project moves**: where things come from and why the steps stand in this order. Goals answer "where to", the route — "by what path".

**Where it comes from here.** A project template is installed — the template puts its route here, and `Intent`'s work reduces to a check. No template — the file stays this blank, and `Intent` with the human works the route out at the fifth interview position, on a par with the other four. The status is the "Project template" field in `PROJECT.md`.

## Out of scope

Work deliberately taken outside the boundary of the idea. There is no coming back from here: if it returns, the boundary was redrawn, and that is a new idea, not a continuation.
