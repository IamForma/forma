# Глоссарий

Термины предметной области проекта — что это *есть*, одно-два предложения, без реализации (`AGENTS.md` §6). Пишет `Intent` сразу, как термин снят, не пачкой. Спорное слово — выбрать одно, остальные под _Избегать_. Источник формата — [mattpocock/skills, `domain-modeling/CONTEXT-FORMAT.md`](https://github.com/mattpocock/skills/tree/main/skills/engineering/domain-modeling), адаптирован.

Формат строки:

```md
**Термин**:
Что это, одно-два предложения.
_Избегать_: синоним, синоним
```

## Язык

Терминов пока нет — первый появится на первом интервью.
