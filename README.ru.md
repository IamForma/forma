# Форма

[English](README.md) · **Русский**

Пятиузловой протокол ведения проекта для ИИ-агентов: `Intent` (замысел), `Spec` (нарезка), `Kit` (снаряжение), `Run` (исполнение), `Core` (вердикт круга). Работает в Claude Code; адаптеры Codex и Gemini — в работе.

## Установка

**Нужно:** Node 18+, Git, Claude Code. Для доски — VS Code (или Antigravity) с расширением Kanban Markdown.

### Способ 1 — установщик (рекомендуется)

Из папки целевого проекта:

```
npx github:IamForma/forma init
```

Ставит ядро (`AGENTS.md`, роли, хуки, доску, дашборд, `manual/`) и задаёт несколько вопросов:

1. **Движки** — `claude` (готов); `codex`, `gemini` — пока не готовы.
2. **Шаблон проекта** — без шаблона (маршрут вырабатывается в интервью) или готовый, например `forma-wordpress-novamira`.
3. **Канбан-доска** — найти редакторы и поставить Kanban Markdown или пропустить.
4. **Язык документов** — `en` (по умолчанию), `ru` или другой код языка.
5. **Окно автосжатия** — для Claude Code, по умолчанию 250000 токенов (см. «Версия и обновление»).

Без вопросов: `npx github:IamForma/forma init --engines claude --template none --board auto`.

Повторный запуск — **обновление**: схема перезаписывается, `project/`, доска и `living/` не трогаются. В реестре npm пакета нет (имя `forma` там занято) — только `github:`.

### Способ 2 — git-клон

```
cd целевой-проект
git clone https://github.com/IamForma/forma.git protocol
```

Затем в сессии Claude Code, открытой в целевом проекте:

```
прочитай protocol/skills/forma/SKILL.md и установи по нему протокол Форма
```

Обновление: `git -C protocol pull`, затем «обнови протокол Форма». Клон — вложенный репозиторий, его файлы в историю проекта не попадают.

### Способ 3 — плагин Claude Code

```
claude plugin marketplace add IamForma/forma
claude plugin install forma@forma
```

Затем в проекте: «установи протокол Форма» (или `/forma`). Если после `marketplace update` обновление не появилось — кэш плагина устарел, переходите на способ 2.

### Модели узлов

Задаются полем `model:` каждой роли в `.claude/agents/`. По умолчанию:

| Узел | Модель |
|---|---|
| `Intent`, `Kit`, `Core` | `claude-opus-5-5` |
| `Spec`, `Run` | `claude-sonnet-5` |
| `extractor` (помощник) | `haiku` |

Модель меняется правкой этой строки. Обновление перезаписывает роли — держите свою правку в заметке и повторяйте после обновления.

### Шаблоны проектов

Шаблон добавляет поверх ядра готовый маршрут под конкретный тип дела. Выбирается в установщике (вопрос 2) или ставится отдельно:

| Шаблон | Для чего | Плагином |
|---|---|---|
| [`forma-wordpress-novamira`](templates/forma-wordpress-novamira/README.md) | WordPress через Novamira MCP (+ Elementor), Aura/Magnific | `claude plugin install forma-wordpress-novamira@forma` |

При способе 2 шаблоны уже лежат в `protocol/templates/<имя>/`: скопируйте его `skills/` в `.claude/skills/`, затем попросите агента прочитать `protocol/templates/<имя>/skills/<имя>/SKILL.md` и установить шаблон по нему.

### Канбан-доска (обязательно)

```
code --install-extension LachyFS.kanban-markdown
```

Доска `.devtool/features/` — место, где живут статус карточек, история, результат и расход. Без неё у дашборда, графа и сверки критериев нет данных.

### После установки

- Дашборд: `node dashboard/serve.js` → `http://localhost:5050/`.
- Задайте два порога (заходы, объём) в `project/config/PROJECT.md`.
- Начните подготовку по `project/config/SETUP.md` — интервью ведёт `Intent`, основная сессия.

По желанию: `skill-creator`, `context-mode`, `agentmemory` — см. полное описание.

## Версия и обновление

- **Какая версия стоит.** Первая строка вывода установщика — `Forma <версия> → <папка>`. Без установки: `npx github:IamForma/forma --version`. В проекте: поле `version` в `.forma/install-manifest.json`.
- **Уведомление об обновлении.** Раз в сутки при старте сессии Claude Code хук сравнивает установленную версию с последней на GitHub и говорит только тогда, когда на GitHub версия новее. Работает без `gh` (тогда обычным запросом) и молчит без сети.
- **Обновить.** Снова запустите `npx github:IamForma/forma init` в папке проекта — `project/`, доска и `living/` сохраняются.
- **Окно автосжатия.** Установщик предлагает задать для проекта окно автосжатия Claude Code в 250000 токенов (`.claude/settings.json`). Своё значение (переменная окружения, `~/.claude/settings.json`, `.claude/settings.local.json`) он не перекрывает. Без вопросов: `--compact <токены>` задаёт другое значение, `--compact off` оставляет умолчание Claude Code.

## Если что-то не работает

- **Установщик ничего не вывел и вернулся к приглашению.** Запустите ту же команду ещё раз; если повторилось, удалите папку `_npx` внутри кэша npm (`npm config get cache`) и повторите. Обычная причина — устаревший кэш `npx`.
- **Хуки ничего не делают (нет проверки карточки, защиты от удаления, стартового сообщения).** Claude Code запускает все хуки через `bash`. На Windows поставьте Git for Windows (в нём есть Git Bash) и запустите установщик снова — он выводит предупреждение, если рабочего `bash` не нашёл. Проверить результат: `node .forma/verify/verify-install.cjs`.
- **Команда заблокирована хуком guard-delete («Заблокировано хуком guard-delete…»).** Папки и файлы самой схемы (`.claude/`, `.agents/`, `.codex/`, `.devtool/`, `.forma/manual/`, `.forma/living/`, `AGENTS.md`, `PROJECT.md`, любой `GOAL.md`) защищены от удаления и от переноса наружу. Чтобы разрешить ровно одну такую команду, напишите в своём сообщении кодовую фразу из `AGENTS.md` §2; разрешение расходуется на следующей же команде.

## Что это

![Пять узлов](assets/five-nodes.svg)

**Главный тезис: агент не может проверить сам себя.** Один агент на длинной дистанции в одном контексте не ломается — он тихо вырождается: впечатление подменяет проверку по факту, и результат съезжает к похожему, но не тому. «Форма» отвечает устройством, а не советом: пять отдельных узлов, у каждого своя узкая роль; каждая задача сверяется по записанному признаку; **ни один узел не подтверждает свою же работу**.

Пятеро — одно тело. Каждый судит своей парой критериев, и у каждого своя типичная потеря:

| Узел | Судит | Держит | Теряет, если пара распалась |
|---|---|---|---|
| `Intent` | красиво | справедливость | обобщение |
| `Spec` | просто | совершенство | опущение |
| `Kit` | естественно | закон | искажение |
| `Run` | честно | человечность | подмена |
| `Core` | индивидуально | истинный путь | карта не территория |

Каждая потеря в момент совершения выглядит разумной — поэтому её ловит отдельный узел, а не бдительность.

- **Маршрут.** `Intent → Spec → Kit → Run → Intent`. Прямого возврата в `Run` нет: карточку всегда пересобирает `Kit`.
- **Память.** `Intent` — основная сессия с человеком; `Spec`, `Kit`, `Run`, `Core` — изолированные вызовы без общей памяти. Рост живёт в файлах (`JOURNAL.md`, `VALUE.md`, скиллы), а не в памяти модели.
- **Инструменты по роли.** `Spec` и `Core` только читают и пишут файлы; инструменты, меняющие продукт, получает только `Run` в снаряжение, на одну задачу.
- **`Core`** стоит в стороне: вступает только при нарушенном пороге или закрытии круга и выносит вердикт «дошли / не дошли».
- **Доска.** Те же пятеро как канбан: `Spec` → `Kit` → `Run` → `Intent`, `Core` — под всеми четырьмя.

Закон — `AGENTS.md` (§1–7, на английском — родном языке модели, ~39% меньше токенов). Пояснения — `manual/en/`, `manual/ru/`.
